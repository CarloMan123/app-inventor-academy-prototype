# App Inventor Academy · MVP prototype

Interactive mid-fidelity prototype of **App Inventor Academy (AIA)**, a teacher-training platform where educators learn MIT App Inventor, apply it with their students and earn a micro-credential backed by real classroom evidence.

**Live prototype:** https://carloman123.github.io/app-inventor-academy-prototype/

The prototype is in English and can be switched to Spanish from any screen (EN / ES button).

## Screens

| Screen | Purpose | Hypothesis |
|---|---|---|
| P1 Welcome | Navy hero with "Teach programming. Certify it. Transform your career.", "Start for free" CTA, social proof and 3 feature cards | H1, H3 |
| P2 Register | 6 fields (name, email, country, teaching level, main area, password) and a "less than 3 minutes" indicator | H1 |
| P3 Dashboard | Personal greeting, one clear "Your next step", recommended path and stats | H2 |
| P4 Module 1 | 3 steps with duration and expected result, "Start Module 1" button | H3 |
| P5 Activity | "Your mission: take it to your classroom", 3 evidence types, 3 teacher examples | H3, H4 |
| P6 Evidence | Progress bar to 100% and 3 steps: file, description, context | H4 |
| P7 Certificate | "Evidence verified", specific competency text, teacher data, share on LinkedIn and download | H5 |
| P8 Upgrade | 1 of 3 modules progress, locked Module 2, Free / Educator $12 / Institutional $8 plans | H6 |

A short feedback form follows P8.

## How to test it

1. Open the live prototype on a phone or a computer.
2. Explore it as a teacher and think aloud.
3. Use **Restart test** before the next participant.

Everything a participant types stays in their own browser. This GitHub Pages version does not send data anywhere.
